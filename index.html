WHY OPEN INNOVATION?

The machine is yours to change.

Afterlight uses an open-weight text-generation model directly in the browser through Transformers.js. There is no Ollama installation and no hosted inference API. The model files download once, then inference runs on your device. A fallback generator keeps the demo usable if model loading fails.
